# ROI 确认与参数调优

**何时读**：换新视频；字幕位置看起来不在默认 ROI 内；结果条数明显偏多或偏少；想调投票 / 归并 / 置信度参数。

## ROI 确认流程

字幕区（Region of Interest）用两个比例参数描述，`--roi-top` 是上边界、`--roi-bot` 是下边界，取值 0~1（相对画面高度）：

```bash
<python> scripts/hardsub_extract.py "<视频>" --out "<dir>/probe" \
  --seconds 120 --keep-frames --source-url "<URL>"
```

然后打开 `<dir>/probe/_frames/*.png`，逐张判断：

- 字幕是否**完整**在框内（上沿没被切、下沿没被切）；
- 有没有把无关画面（大片背景）也框进来——框太大不只浪费时间，还可能把别的文字也检出来。

调整方向：

- 字幕**上沿被切** → 把 `--roi-top` 调**小**；
- 字幕**下沿被切** → 把 `--roi-bot` 调**大**；
- 框内太空旷（字幕只占很小一条） → 上下收窄，让 ROI 更贴合字幕带。

**ROI 是比例值，与分辨率无关。** 同一个视频从 480p 换到 1080p，不需要改 ROI 参数。但它与「字幕在画面中的位置」有关——换片必须重新确认。

## 默认值从哪来

本 skill 的默认 `--roi-top 0.78 --roi-bot 0.98` 是针对一类视频调的：

- 字幕样式：**白色字体 + 黑色描边**；
- 位置：**底部居中**；
- 实测字幕带位于画面高度 y **82% ~ 96.6%**。

0.78 / 0.98 就是在 82%~96.6% 上下各留了一点余量得到的。**它不是普适常量。**

## 参数表

| 参数 | 默认 | 含义 | 什么时候调 |
|---|---|---|---|
| `--roi-top` | 0.78 | 字幕区上边界（画面高度比例） | 换片必查；字幕上沿被切就调小 |
| `--roi-bot` | 0.98 | 字幕区下边界 | 换片必查；字幕下沿被切就调大 |
| `--vote-n` | 3 | 滑动投票窗口大小（帧） | 画面抖动导致字幕时断时续时，可加大 |
| `--vote-k` | 2 | 窗口内至少 K 帧检出才算「有字幕」 | 与 `--vote-n` 配合：噪声大就提高 k/n |
| `--sim` | 80 | rapidfuzz 文本相似度归并阈值（0~100） | 同句被拆成多条 → 适当降低；不同句被错误合并 → 提高 |
| `--merge-gap` | 0.35 | 允许归并的最大时间间隙（秒） | 同句被拆成多条且中间有空档 → 提高 |
| `--min-dur` | 0.30 | 最短字幕时长（秒），短于此的段被丢弃 | 出现大量一闪而过的碎片条目 → 提高 |
| `--conf` | 0.75 | OCR 置信度过滤下限 | 有 UI 文字混入 → 提高；正常字幕被误滤掉 → 降低 |
| `--seconds` | 0 | 只处理前 N 秒（0 = 全片） | 小样验证、快速试参数 |
| `--keep-frames` | 关 | 保留每段中间帧截图到 `_frames/` | 核对 ROI、检查识别质量 |
| `--route` | paddleocr-tf | 推理后端 | 仅 GPU 不可用时改 `rapidocr`（且只用于小样本） |
| `--source-url` | 空 | 写入 `.srt` 第 1 行的来源链接 | **本 skill 要求必传** |

## 症状 → 调参对照

| 症状 | 先看 | 处置 |
|---|---|---|
| 小样 `_frames` 里字幕被切边 | ROI | 按上面的方向调 `--roi-top` / `--roi-bot` |
| 小样 `_frames` 全空（没问题画面却检出 0 字） | ROI | 框可能没对准字幕，先确认字幕真的在框内 |
| 小样 `_frames` 全满（连背景都检出了） | ROI | 框开得太大，收窄 |
| 条数明显偏少 / 整句丢失 | 先排除教训 3 | 确认脚本没被改成「只 OCR 中间帧」；再看看 `--sim` / `--merge-gap` 是否把不同句合并了 |
| 条数明显偏多、大量碎片 | 归并参数 | 提高 `--min-dur`；必要时提高 `--sim` |
| 同句被拆成多条 | 归并参数 | 降低 `--sim`，或提高 `--merge-gap` |
| 出现界面 / 水印文字 | 置信度 | 提高 `--conf`（几何过滤已能挡掉大部分） |
| 时间轴抖动（起止时间飘） | 投票 | 加大 `--vote-n` / `--vote-k`（例如 5/3） |
| 繁体偶发混入 | 后处理 | 属 PP-OCR 已知特性；需要强简体时在 `.srt` 之后接 opencc，不在脚本内做 |

## 先小样后全片

任何参数调整都**先在 `--seconds 120` 小样上验证**，看着 `_frames` 和条数确认改善，再放行全片。全片一次 20 分钟量级，拿全片试错代价太高。
